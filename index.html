iPhone「健康」App 的体重/睡眠数据可以真·全自动同步进来：用 iPhone 自带的「快捷指令」读取健康数据，设一次每天 8:00 的自动化，数据就会自动上传云端，工作台打开时自动入库、曲线自动更新——之后你什么都不用做。WiFi 体重秤只要在厂商 App 里开了「同步到苹果健康」，数据就会顺着这条链路全自动流过来。

🟢 健康通道已开启　

📱 iPhone 一次性设置教程（约3分钟，设好即永久自动）

第一步：建快捷指令

  • 打开 iPhone「快捷指令」App → 右上角 ➕ 新建，命名「健康同步」
  • 添加操作「查找健康记录样本」→ 类型选「体重」→ 排序「开始日期·最新优先」→ 限额 1
  • 添加操作「文本」，内容写一行：当前日期,体重（两个都从变量选；点「当前日期」变量，格式改为自定 yyyy-MM-dd；想加睡眠/消耗热量就继续往后拼，见下方说明）
  • 添加操作「获取 URL 内容」→ URL 填 https://textdb.online/update → 展开选项：方法 POST、请求体选表单，加两个字段：key = 上面的通道码、value = 文本（选「文本」变量）
  • 点 ▶ 运行一次测试 → 回到这里点「🔄 立即拉取」，看到体重入库就成功啦

第二步：设自动化（此后全自动）

  • 「快捷指令」底部「自动化」→ ➕ →「特定时间」→ 每天 8:00 → 运行「健康同步」→ 选「立即运行」（不询问）

💤 加睡眠：再加「查找健康记录样本·睡眠分析」，文本写成 当前日期,体重,睡眠小时数。
🔥 加消耗热量 / 基础代谢（看体重与热量关系）：再加两个「查找健康记录样本」→ 分别选「活动能量」「基础能量」→ 各接一个「计算统计数据·总和」→ 再用「计算」把两者相加 = 每日总消耗。文本共五段：当前日期,体重,睡眠小时数,每日总消耗,基础代谢（睡眠/消耗可选，顺序固定不能乱）。安卓可用 MacroDroid/Tasker 同样 POST，需要教程告诉我～

📥 账单一键导入 支付宝 / 微信 / 银行卡

淘宝、拼多多、京东、抖音的付款最终都经过支付宝 / 微信 / 银行卡扣款，所以只需导入这两三份账单，就覆盖了几乎全部交易。导入时自动识别平台（备注标注 淘宝/京东/拼多多/抖音）、自动分类、自动按交易单号去重——同一份账单重复导入不会记重。
📱 各平台账单怎么导出？（点开看步骤）
  • 支付宝：我的 → 账单 → 右上角「···」→ 开具交易流水证明 → 用于个人对账 → 选时间范围 → 发送至邮箱 → 下载 ZIP（解压密码在邮件里）得 CSV
  • 微信支付：我 → 服务 → 钱包 → 账单 → 右上角「常见问题」→ 下载账单 → 用于个人对账 → 邮箱收 ZIP 解压得 CSV
  • 银行卡：手机银行 App → 明细 → 导出流水（Excel 需先另存为 CSV）；或整理成通用三列格式：日期,金额,备注（支出写负数，如 2026-07-27,-35.5,午餐）
  • 建议每周一花 3 分钟导入一次（任务清单每周一会自动提醒你）✨
